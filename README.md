# Лабораторная работа: Разработка схемы динамического пароля. Электронная цифровая подпись

## Файлы проекта:
- `gui_app.py` — Главное графическое приложение с двумя окнами («Отправитель» и «Получатель»), в точности повторяющее интерфейс из задания.
- `rsa_core.py` — Математическое ядро RSA: генерация 31-битных простых чисел, шифрование, расшифрование, наложение и проверка ЭЦП (SHA-256).
- `dynamic_password.py` — Скрипт расчета схемы динамических паролей $Y = (X \bmod 100) \cdot D + W$.
- `create_word_report.py` — Скрипт автоматической генерации отчета в формате Microsoft Word (`.docx`).
- `Лабораторная_работа_Динамический_пароль_ЭЦП.docx` — Готовый файл отчета.

## Быстрый запуск:
```bash
python gui_app.py
```
После запуска откроются два окна: «Отправитель» слева и «Получатель» справа.
1. Нажмите «Сформировать ключи» в обоих окнах.
2. Нажмите «Послать» в окне Получателя (для передачи ключа шифрования) и в окне Отправителя (для передачи ключа подписи).
3. Введите текст (например, «Привет») в окне Отправителя.
4. Нажмите «Закодировать и подписать».
5. Нажмите «Послать».
6. В окне Получателя нажмите «Проверить».
